# option63

**option63** is a toolkit for manipulating vCard data. Type-safe Rust library and CLI. More stuff coming.

## Rust library usage

Add **o63** to your project's `Cargo.toml`:

```toml
[dependencies]
o63 = "0.1"
```

Then parse and inspect a vCard from Rust code:

```rust
use o63::vcard::VCard;
use o63::vcard::property::EmailProperty;
use o63::vcard::property::PropertyBase;

fn main() {
    let (_, vcard) = VCard::parse(
        b"BEGIN:VCARD\r\nVERSION:4.0\r\nEMAIL;PREF=1:john@example.com\r\nEMAIL;PREF=2:jdoe@example.net\r\nEND:VCARD\r\n",
        false,
    )
        .unwrap();

    // Retrieves the preferred email address based on the priority from the `PREF` param
    if let Some(email) = vcard.get_preferred::<EmailProperty>() {
        println!(
            "preferred email: {}",
            String::from_utf8_lossy(&email.value_to_vcard_vec())
        );
    }
}

```

Open the HTML documentation generated by `cargo doc --package o63` to browse the full API.

## CLI usage

You'll need to have **Rust** installed on your system.

Install the CLI from [crates.io](https://crates.io/crates/o63_cli) (the binary is named `o63`):

```bash
cargo install o63_cli
```
Create a test vCard file and try the commands below:

```bash
# show CLI commands and options
o63 --help

# create a test vCard file (contacts.vcf) used in the examples below
cat > contacts.vcf <<'EOF'
BEGIN:VCARD
VERSION:4.0
FN:John Doe
N:Doe;John;;;
EMAIL:john@example.com
TEL:+33-1-23-45-67-89
TEL;TYPE=CELL:+33-6-23-45-67-89
END:VCARD
EOF

# validate and display a vCard as parsed by option63
o63 vcard show contacts.vcf
# keep only an allow-list of properties from a vCard
# useful to create ad-hoc vCards to preserve the privacy of your contacts in some environments
o63 vcard show contacts.vcf --props N,TEL
# drop a property, optionally only where the value matches a regex
o63 vcard drop contacts.vcf TEL --regex '^\+33-6'
# pipe input to read from stdin ('-' as input) and pipe output to another command
cat contacts.vcf | o63 vcard show - --props N,TEL | o63 vcard drop - TEL --regex '^\+33-6'
```
