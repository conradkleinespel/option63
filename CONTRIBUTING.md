# Contributions

## No code contributions, but issues and feedback are welcome

This project currently does not accept outside code contributions, pull requests, or patches.

However, you can contribute in several other ways:

- **Report issues**: Bug reports are very much welcome, please include reproduction steps and code samples
- **Feedback**: Tell us about your current or future use-cases, we want to learn what we can improve

## Why we currently don't accept outside code contributions

We are planning to monetize the project by offering commercial licenses in the future. Accepting outside code contributions under the AGPLv3 license would require a Contributor License Agreement (CLA) to maintain these options, which adds complexity not warranted at this point in time.
